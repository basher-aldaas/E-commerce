# E-commerce Project

## Clone the Repository

```bash
git clone https://github.com/basher-aldaas/eco-requirement1.git
```

## Navigate to the Project Directory

```bash
cd eco-requirement1
```

## Create Environment File

**Windows PowerShell:**
```powershell
Copy-Item .env.example .env
```

**Linux / macOS:**
```bash
cp .env.example .env
```

## Build and Run Docker Containers

```bash
docker compose up -d --build
```

## Check Running Containers

```bash
docker compose ps
```

## Access the Application

Open your browser:

http://localhost:8000
